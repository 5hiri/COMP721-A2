Description: MySQL table creation script for the CabsOnline booking system.
This file contains the SQL command to create the 'bookings' table that stores
all taxi booking requests. The table structure includes all required fields
as specified in the assignment requirements:
- booking_number: Primary key with BRN##### format
- Customer information: name, phone, address details
- Pickup information: date, time, location details
- System fields: booking timestamp and assignment status

Command to create table:
CREATE TABLE bookings (
    booking_number VARCHAR(10) PRIMARY KEY,
    customer_name VARCHAR(255) NOT NULL,
    phone_number VARCHAR(20) NOT NULL,
    unit_number VARCHAR(50),
    street_number VARCHAR(20) NOT NULL,
    street_name VARCHAR(100) NOT NULL,
    suburb VARCHAR(100),
    destination_suburb VARCHAR(100),
    pickup_date DATE NOT NULL,
    pickup_time TIME NOT NULL,
    booking_datetime DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    status VARCHAR(20) NOT NULL DEFAULT 'unassigned'
);
